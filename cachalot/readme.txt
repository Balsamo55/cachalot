Un plugin ultraléger pour améliorer les performances de votre site WordPress grâce à la mise en cache, la minification, le lazy loading et plus encore.

== Description ==

Cachalot est un plugin conçu pour optimiser les performances de votre site WordPress avec une approche simple et efficace. Que vous utilisiez Divi, Elementor ou tout autre thème ou constructeur de page, Cachalot améliore les performances en réduisant le temps de chargement de vos pages.

**Fonctionnalités principales :**
- Mise en cache des pages pour des temps de chargement ultra-rapides.
- Minification des fichiers HTML, CSS et JavaScript.
- Lazy loading des images pour améliorer les performances.
- Compression Gzip pour réduire la taille des fichiers envoyés au navigateur.
- Hébergement local des Google Fonts pour minimiser les appels externes.
- Suppression des scripts et styles inutilisés pour alléger les pages.

== Installation ==

1. Téléchargez le fichier ZIP du plugin depuis WordPress.org ou depuis votre tableau de bord WordPress.
2. Allez dans `Extensions > Ajouter` et cliquez sur "Téléverser une extension".
3. Sélectionnez le fichier ZIP, puis cliquez sur "Installer maintenant".
4. Activez le plugin via le menu `Extensions` dans WordPress.
5. Configurez le plugin dans `Réglages > Cachalot`.

== FAQ ==

= Quels sont les prérequis pour utiliser ce plugin ? =
Cachalot nécessite WordPress 5.0 ou une version ultérieure et PHP 7.4 ou plus récent.

= Ce plugin est-il compatible avec tous les thèmes et constructeurs de pages ? =
Oui, Cachalot est conçu pour fonctionner avec tous les thèmes et constructeurs de pages, y compris Divi et Elementor.

= Comment vider le cache généré par Cachalot ? =
Vous pouvez vider le cache en cliquant sur le bouton "Vider le Cache" dans la section d'administration du plugin.

= Puis-je désactiver certaines fonctionnalités ? =
Oui, toutes les fonctionnalités de Cachalot peuvent être activées ou désactivées individuellement dans les paramètres du plugin.
